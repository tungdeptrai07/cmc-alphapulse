Explicit CoinMarketCap API Endpoints Used

All 5 endpoints below are implemented in backend/cmc_client.py and routed via backend/server.py without exposing keys in client code.

1. GET /v1/cryptocurrency/listings/latest — Market rank, price, 24h volume & market cap velocity
2. GET /v2/cryptocurrency/quotes/latest — Targeted multi-symbol watchlist polling
3. GET /v1/global-metrics/quotes/latest — Macro total market cap, BTC/ETH dominance, DeFi share
4. GET /v1/cryptocurrency/info — Project metadata, tags & official URLs
5. GET /v1/cryptocurrency/map — Canonical CMC ID mapping for ticker disambiguation

CoinMarketCap API Developer Feedback (#BuildwithCMC)

Honest engineering notes observed while building CMC AlphaPulse with the CoinMarketCap Pro API.

What the CMC API Made Possible:
• Normalized cmc_rank, volume_24h, and market_cap fields in /v1/cryptocurrency/listings/latest enabled instant calculation of liquidity velocity without stitching together separate exchange APIs.
• /v1/global-metrics/quotes/latest provides clean institutional macro indicators (BTC dominance, DeFi 24h volume share) in a single 1-credit call.
• /v2/cryptocurrency/quotes/latest handles duplicate ticker symbols cleanly via structured arrays.
Where Friction Occurred & Suggested Improvements:
1. Browser CORS Restriction: Direct frontend requests to pro-api.coinmarketcap.com are blocked by CORS (appropriately for key protection), requiring every lightweight web dashboard to deploy a backend proxy (included in backend/server.py). Providing an official ephemeral/scoped read-only client token or official Cloudflare Worker template in docs would accelerate frontend hackathon builds.
2. Tag Filtering on Listings: Adding a native server-side tag=ai or category=rwa query filter directly on /v1/cryptocurrency/listings/latest would avoid fetching 100+ rows just to filter niche sectors client-side.
3. Credit Cost Transparency Header: Returning X-CMC-Credits-Remaining directly in HTTP response headers alongside the JSON body status.credit_count would make client rate-limiting simpler.
